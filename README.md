# LearnHub - Online Learning Platform

LearnHub is a beginner-friendly online learning
platform built to help students explore courses
and track their learning progress.

## Features

- Student registration and login
- Browse and search courses
- Enroll in courses
- View course details
- Lessons for different courses
- Track completed lessons
- Student dashboard
- Profile page
- Responsive design for mobile screens

## Courses

- Web Development
- Python Programming
- Database Fundamentals
- UI/UX Design
- Data Analysis
- Cybersecurity Basics

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Browser Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Register or log in to explore LearnHub.

## Note

This is a student project and a front-end prototype.
Login, registration, enrollments, and progress use
browser Local Storage. It does not use a secure
backend authentication system.
